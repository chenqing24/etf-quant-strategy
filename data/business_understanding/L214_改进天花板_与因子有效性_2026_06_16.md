# L214（etf_strategy 子项目）：改进天花板 + 因子有效性优先（2026-06-16）

## 场景

C8 应用 L213 改进 1/3/5（RSI 放宽 + 3 年回测 + 阈值解耦 + 止损放宽到 -12%），结果仍失败（胜率 26.0% < 50%）。

## 关键发现

### 发现 1：改进有效果，但效果有限

| 改进 | 期望 | 实际 |
|------|------|------|
| RSI 放宽 | 信号密度↑ | ✅ +140% |
| 缩短回测 | 减少噪音 | ✅ 避免 2021-2022 干扰 |
| 阈值解耦 | 权重生效 | ✅ 修复 bug |
| 止损放宽 | 减少被洗出 | ✅ -12% vs -8% 更合理 |

但**所有改进加起来**只能把胜率从 32.6% (C6) → 26.0% (C8)，**反向下降**！

### 发现 2：核心问题不在设计，在因子本身

**3 因子 (MA5/RSI/OBV) 在 A 股 ETF 上预测力不足**：
- MA5: 趋势跟随，A 股 ETF 趋势性弱 → 弱信号
- RSI<40: 即使放宽，超卖仍罕见 → 触发率 < 5%
- OBV: 量能验证，但 ETF 量能数据噪音大 → 弱信号

**单因子 IC 估计 < 0.04，组合后 IC < 0.04（不增反减）**

### 发现 3：A 股 ETF 均值回归的根本问题

- A 股：机构主导 + T+1 + 涨跌幅限制 → **波动率被压低**
- 均值回归策略需要的"剧烈波动"不存在
- 结果：信号触发 → 价格回归幅度小 → 收益覆盖不了成本

## 教训

### 教训 A：改进有天花板，不能无限叠加

**错误思维**：
```
"再调一下 RSI" + "再放宽止损" + "再加 min_n" = 胜率提升
```

**正确思维**：
```
天花板 = f(因子预测力, 市场结构, 成本结构)
- 如果天花板 < 50%（随机），叠加任何设计改进都无效
- 必须换**因子本身**或**市场假设**
```

### 教训 B：先验证单因子有效性，再组合

**错误流程**：
1. 拍脑袋选 3 因子组合
2. 跑回测
3. 发现失败

**正确流程**：
1. **先验单因子 IC**：每个因子单独跑 5 年回测，看 IC > 0.05？
2. **再验两两组合**：3 因子两两组合（共 3 种），看 IC 是否提升
3. **最后 3 因子**：只在两两有效的基础上尝试

### 教训 C：诚实标注"因子无效"

按 SOUL.md 规则 6.1（**错了就错了，不美化**）：
- ✅ 连续 3 次实验失败 = 强烈信号说明**因子本身无效**
- ❌ 不应继续微调，而是承认 + 换方向
- ✅ "因子无效"是有价值的结论（节省后续时间）

### 教训 D：转向机器学习的判断标准

**何时放弃规则策略，转向 ML**：
- 规则策略连续 3+ 次实验胜率 < 35%
- 业界共识：单因子 IC < 0.05 时，规则策略难以超越随机
- ML 优势：自动学习因子组合 + 非线性关系

**何时继续规则策略**：
- 单因子 IC > 0.10（强信号）
- 2-3 因子组合 IC > 0.15
- 但当前情况 IC < 0.05 = 应转向 ML
