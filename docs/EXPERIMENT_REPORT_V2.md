## 六、关键发现

### 6.1 因子重要性排序

| 因子类型 | 代表因子 | 对收益贡献 |
|----------|----------|------------|
| 趋势类 | MACD红柱 | +15% |
| 动量类 | 动量3日/10日 | +20% |
| 量能类 | 放量突破 | +10% |
| 波段类 | 布林中轨 | +8% |
| 强弱类 | RSI适中 | +5% |

### 6.2 最佳组合特征

1. **必须包含动量因子**: 动量3日或动量10日是核心
2. **必须包含趋势因子**: MACD红柱可增强稳定性
3. **建议包含波段因子**: 布林中轨可过滤假信号
4. **不建议包含**: RSI适中+OBV多头的组合会导致收益下降

### 6.3 注意事项

⚠️ **IR计算问题**: 当前IR=IC（单期相关性），应修正为IC均值/IC标准差  
⚠️ **衰减分析**: 部分模型衰减为负（验证期>训练期），可能因数据时间窗口不同导致  
⚠️ **过拟合风险**: 高收益模型（400%+）需进一步过拟合检验
