## 五、评价标准（"3 个一致原则" — 不变形）

### 原则 1：工具调用一致

```python
DataLoader + IndicatorCalculator + RelativeCalculator + FactorBacktester
```

### 原则 2：执行流程一致

```
信号生成 → 回测 → 评价
```

### 原则 3：评价标准一致（**8 核心指标 = 评价标准不能变形**）

| # | 指标 | 类别 | 公式 |
|---|------|------|------|
| 1 | **IC 均值** | 预测能力 | mean(corr(factor, future_return)) |
| 2 | **IR** | 稳定性 | IC_mean / IC_std |
| 3 | **夏普比率** | 收益质量 | (return - rf) / volatility |
| 4 | **最大回撤** | 风险 | max(peak - trough) / peak |
| 5 | **胜率** | 稳定性 | wins / total_trades |
| 6 | **盈亏比** | 收益质量 | avg_win / avg_loss |
| 7 | **盈利期望** | 综合 | win_rate × profit_loss_ratio |
| 8 | **换手率** | 交易成本 | Σ\|trade\| / avg_position_value |

**8 核心指标** = 评价标准（**不能变形**）

**3 个一致原则**：
1. **工具**：必须用 `DataLoader` + `IndicatorCalculator` + `RelativeCalculator` + `FactorBacktester`
2. **流程**：信号生成 → 回测 → 评价
3. **评价**：8 核心指标

## 七、3 个关键诚实标记（按规则 22）

### 诚实标记 1：核心 ETF 池**没有 1 只有完整 5 年数据**
- 数据范围：~1.9 年（2024-07 至今）
- 用户要求"5 年" = **数据范围目标 5 年，实际不可得**
- 方案：跑 5 年范围，**不可得则按可用数据 + 报告诚实标注**

### 诚实标记 2：v9 mission 用的是"近 3 年"数据，**不是 5 年**
- `data/experiments_v9_recompute/data_quality_report.md` 明确写"近 3 年"
- 用户的"5 年"是**新约束**，与 v9 现状不一致
- 方案：扩展数据范围到 5 年，**先验数据完整性**再跑回测

### 诚实标记 3：分 6 批 × 6 因子 = 36 个，**不是一次挖完**
- 按 SOP-01 v1.1 严格走：每批 4 步（业务理解 → 相关性 → 扣成本回测 → WalkForward）
- 1 批 = 1 个周末（~7 小时）
- 6 批 = **6 个周末（1.5 个月）**
- 风险：长期任务，需要小步提交 + 阶段性回顾
