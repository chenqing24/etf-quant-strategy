## 二、核心发现：为什么IR全部为负？

### 2.1 IC分布统计

| 指标 | 数值 |
|------|------|
| IC范围 | -0.072 ~ 0.077 |
| IC均值 | -0.043 |
| 负IC占比 | 78.6% |

### 2.2 原因分析

**IC为负意味着**：因子信号(MACD红柱>0)与未来5日收益**负相关**

这可能是因为：
1. **均值回复效应**：MACD>0时（多头信号），短期涨幅已大，未来5日倾向回调
2. **入场时机问题**：趋势确认后再入场，已错过最佳买点
3. **IC计算窗口不匹配**：因子是趋势指标，但IC计算的是5日收益

### 2.3 重要结论

⚠️ **IR标准对于短期动量策略不适用**
- IC/IR是因子选股指标，衡量**选股能力**
- 本策略是**趋势跟踪+风控**，收益来自止损止盈
- 风控有效（收益为正），但纯因子选股效果差（IC为负）

**修正评价标准**：不用IC/IR，改用：
- 交易收益（test_return）
- 样本外稳定性（oos_decay）
- 夏普比率（sharpe_ratio）
- 胜率（win_rate）

## 五、关键结论

### 5.1 策略核心

| 要素 | 说明 |
|------|------|
| **因子类型** | 趋势跟踪 + 动量 |
| **风控机制** | 止损-6%，止盈+12%，超时5天 |
| **收益来源** | 风控有效（弥补因子IC为负） |

### 5.2 最佳因子组合

1. **必须包含**：动量3日或动量10日
2. **建议包含**：MACD红柱（增强趋势）
3. **可选包含**：布林中轨（过滤假信号）
4. **不建议依赖**：IC/IR（短期动量策略不适用）

### 5.3 教训总结

| 教训 | 应用 |
|------|------|
| 发现IR计算错误立即修复 | 本次修复了IC/IR计算逻辑 |
| 异常现象要追问原因 | 发现IC为负，深入分析后修正评价标准 |
| 反思要深入 | 区分"选股能力"(IC)和"趋势跟踪"(风控) |
| 完成计划≠完成目标 | 目标是找到有效策略，不是跑完模型 |
