## 七、执行流程

```
Step 1: 调研工具
  └─ 搜索现有代码库（必须！）
      ├─ DataLoader → 数据加载
      ├─ IndicatorCalculator → 指标计算
      └─ FactorBacktester → 回测引擎

Step 2: 配置参数
  └─ 止盈6%，止损4%，持仓3-20天

Step 3: 单因子测试（13个）
  └─ 每个因子单独回测

Step 4: 组合测试（286个）
  └─ 3因子组合全面测试

Step 5: 过拟合检验
  └─ 滚动窗口 + 蒙特卡洛 + 交叉验证

Step 6: 生成报告
  └─ Top模型 + 策略建议
```
