## 3. 核心概念

### 3.1 市场状态分类（v1.2 最终方案）

> **决策**：放弃复杂阈值调优，采用简化判断标准

| 状态 | 判断标准 | 处理 |
|------|---------|------|
| **趋势市** | 有 v8_sop 买入信号（评分≥6） | 执行买入 |
| **震荡市** | 无 v8_sop 买入信号 | 空仓观望 |

**判断逻辑**：
```python
# decision.py run_full_evaluation()
if signals:  # 有 v8_sop 信号
    market_mode = "趋势市"
    execute_trades(signals)
else:
    market_mode = "震荡市"
    # 不触发新买入
```

> **原理**：v8_sop 7因子已内置趋势判断（MACD + MA + ADX + OBV + RSI + 量能），有信号=趋势市。

### 3.2 策略配置

| 模式 | 仓位 | SL | SP | MH | 状态 |
|------|------|-----|-----|-----|------|
| **趋势市** | 100% | -6% | +10% | 5天 | ✅ 已实现 |
| **震荡市** | 0% | - | - | - | ✅ 空仓 |
