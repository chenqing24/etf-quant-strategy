## 九、关键发现

### 9.1 相对大盘因子有效
- **100% Top10包含相对因子**：验证了问题诊断的正确性
- 相对MACD、相对资金流、相对ADX是最有效的因子

### 9.2 策略显著跑赢大盘
- 绝对收益1000%+，相对收益1000%+
- 夏普比率3.0+，时序稳健（滚动100%）

### 9.3 评价体系严格
- 无S/A级模型因回撤门槛较高（<15%）
- 290个B级模型可作为候选池

### 9.4 核心因子模式
- **趋势类**：MACD红柱 > SAR趋势 > ADX趋势
- **相对大盘类**：相对MACD强势 + 相对资金流入 + 相对ADX强势
