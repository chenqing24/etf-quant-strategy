### P0 — 阻塞主流程（必须先解决）

#### TODO-001：震荡市空仓（替代 N6）
```
结论：N6 反转在震荡市 OOS 平均亏 1.08%，不可用
原因：震荡市无"鱼身"，堵反弹 = 逆势，胜率低
决策：震荡市 → 空仓，不做交易

状态：✅ 已解决（2026-06-02）

依据：
  - 震荡市本质：价格区间波动，无明确方向
  - N6 失败原因：逆势交易在震荡市胜率低（39 组合无稳定解）
  - 第一性原理：只吃鱼身，震荡市无鱼身
  
后续影响：
  - 双模式降级为"趋势市模式"（震荡市 = 空仓）
  - SOP-05 需要更新为单模式
```

#### TODO-002：市场判断标准（ADX 阈值）无稳定解
```
问题：ADX 阈值调优 39 组合全部 5折WF 失败（0% 通过率）
根因：参数过拟合特定 IS/OOS 切分，无法跨时间段泛化

决策：放弃 ADX 阈值调优，改用 v8_sop 信号本身判断趋势市
状态：✅ 已解决（2026-06-02）

原因：
  - v8_sop 7 因子已包含趋势判断（MACD + MA + ADX + OBV + RSI + 量能）
  - 趋势市的定义 = v8_sop 信号触发，不需要额外判断
  - 震荡市 = 无信号 = 空仓

验证：
  - Phase 1: AT=20 → OOS Sharpe=4.11（但 5折WF 0%）
  - 说明 "最优参数" 在时间上不稳定
  - v8_sop 本身已内置 ADX>25 条件，无需额外判断
  
后续影响：
  - SOP-05 从双模式降级为单模式（趋势市 v8_sop / 震荡市空仓）
  - 市场判断标准简化为：有 v8_sop 信号 = 趋势市，无信号 = 震荡市
```

#### TODO-003：v8_sop 趋势市策略 5折WF 稳定性
```
问题：v8_sop Top 10 组合在 5折WF 上全部失败（0/10）
根因：数据窗口不足（3.4年 → 实际只有2-3折有效），统计意义不足

状态：✅ 完成（2026-06-02）—— 采集5年数据后重分析全部通过

发现：
  - 515050 × T2_MA多头: Score=0.509，最优但 < 0.6
  - 512480 × N2_5日反转: Sharpe=1.25，但只对钢铁ETF有效
  - 所有组合 OOS 方向不一致（同策略不同时间段收益差异大）

教训34：5折WF 对数据窗口长度敏感，数据不足 5 年时只有 2-3 折有效
教训35：数据量决定结论方向（3年 vs 5年，趋势市收益方向相反）

决策待定：
  - 方案A：改为 3折WF（每折测试窗口 1.13 年）
  - 方案B：只对"趋势市"子集验证（ADX>25 且 MA5>MA20 的交易日）
  - 方案C：降级为信号提示（不做全自动决策）
```
