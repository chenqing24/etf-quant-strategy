## 二、实验设计阶段

### 2.1 ETF股票池定义

| 分类 | 数量 | 用途 |
|------|:----:|------|
| 挖掘+验证 | 14只 | 主要实验对象 |
| 大盘参考 | 1只 | 510300（沪深300） |

**要求**：每只ETF必须有足够数据天数（≥365天）

### 2.2 时间分割

| 阶段 | 时间范围 | 用途 |
|------|----------|------|
| **训练期** | ~截止日期前2年 | 因子发现+参数优化 |
| **验证期** | 最后1年 | 样本外验证 |

**原则**：验证期必须是真正的"样本外"，不能用于任何参数调优

### 2.3 因子池定义

| 类别 | 因子 | 说明 |
|------|------|------|
| 趋势类 | MACD, MA多头, SAR | 趋势方向确认 |
| 动量类 | RSI, KDJ, 动量(N日) | 超买超卖/趋势延续 |
| 量价类 | OBV, 放量, 量价背离 | 资金流向 |
| 波动类 | 布林带, 低波动 | 突破信号/风险指标 |
| 大盘类 | 大盘MA多头 | 市场状态 |

### 2.4 组合覆盖策略

| 组合类型 | 数量 | 说明 |
|----------|:----:|------|
| 单因子 | N个 | 基础筛选 |
| 3因子组合 | C(N,3) | 重点验证 |
| **过滤策略** | 前20% | 按业界实践筛选 |

## 三、实验执行阶段

### 3.1 执行要求

#### 记录开始时间

```markdown
# 实验日志

## 阶段1: 单因子测试（17个）
- 开始时间: 14:30
- 结束时间: 14:35
- 耗时: 5分钟
```

#### 每10个模型停下反思

```
累计10个模型
    ↓
记录当前结果（pass/fail分布）
    ↓
检查清单:
  [ ] 通过率是否合理？（>5%说明方向有效）
  [ ] 是否有异常模式？（全pass可能是过拟合）
  [ ] 新发现是什么？
    ↓
决策:
  - 继续：方向有效，继续
  - 优化：参数有问题，调整
  - 放弃：方向无效，换方向
```

### 3.2 时间估算

| 阶段 | 数量 | 单次耗时 | 总耗时 |
|------|:----:|:--------:|:------:|
| 单因子测试 | 17个 | 15秒 | ~5分钟 |
| 3因子组合 | 136个 | 15秒 | ~30分钟 |
| 过拟合检验 | - | - | ~10分钟 |
| **总计** | - | - | **~45分钟** |

### 3.3 异常处理

| 情况 | 处理 |
|------|------|
| 模型运行报错 | 记录错误 → 标记为fail → 继续下一个 |
| 结果异常（负收益） | 检查数据/因子计算 → 修复 → 重跑 |
| 内存不足 | 减少批量大小 → 分批执行 |

## 四、结果分析阶段

### 4.1 统一评价指标

| 类别 | 指标 | 通过标准 | 说明 |
|------|------|:--------:|------|
| **核心收益** | 测试收益 | >5% | 验证期收益 |
| | 样本外衰减 | >-50% | (测试-训练)/训练 |
| **风险调整** | 夏普比率 | >0.5 | (Rp-Rf)/σp |
| | 最大回撤 | >-20% | 最大跌幅 |
| **交易效率** | 胜率 | >40% | 盈利交易占比 |
| | 盈亏比 | >1.0 | 平均盈/平均亏 |
| **稳定性** | IC | >0.02 | 因子-收益相关 |
| | IR | >0.4 | IC均值/标准差 |

### 4.2 IC/IR分析

```python
# IC = Correlation(因子值, 未来收益)
# IR = IC_mean / IC_std

IC解读:
  IC > 0: 正向（因子值越大，收益越高）
  IC < 0: 反转（因子值越大，收益越低）
  |IC| > 0.02: 有效
  IR > 0.4: 稳定
```

### 4.3 过拟合检验

| 方法 | 说明 |
|------|------|
| 滚动窗口验证 | 不同时间段是否有效 |
| 蒙特卡洛检验 | 随机因子是否也能通过 |
| 参数敏感性 | 参数微调是否导致结果大幅变化 |
