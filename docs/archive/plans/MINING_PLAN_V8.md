## 一、历史实验教训与成功总结

### 1.1 各版本核心发现

| 版本 | 核心发现 | 成功 | 失败 |
|------|----------|------|------|
| **v2** | 发现动量3日+布林中轨组合 | 高收益466.7%，样本外衰减问题 | 部分模型衰减-55% |
| **v3** | 揭示"交易驱动"vs"alpha驱动"问题 | 过拟合检验纳入流程 | 单笔收益≈随机，0%通过 |
| **v5** | 布林上轨突破+RSI适中最优 | 单笔1.37%，夏普3.09 | 总收益95.5%偏低 |
| **v6** | 标准化工具链+过拟合验证 | 单笔1.08%，夏普2.78，超额300% | 核心指标50.8%，过拟合39.5% |

### 1.2 核心教训（v8必须解决）

| # | 教训 | 影响 | 解决方案 |
|---|------|------|----------|
| **1** | 单笔收益≈随机（v3） | 高收益来自大量交易，非alpha | **提高单笔目标：>1.0%** |
| **2** | 过拟合通过率低（v6: 39.5%） | 策略稳定性不足 | 优化过拟合检验参数 |
| **3** | 样本外衰减严重（v2） | 训练期过拟合 | 增加验证窗口数量 |
| **4** | 交易频率过高（v3） | 成本累积，效果稀释 | **降低频率：精选交易** |
| **5** | 止盈止损不当（v2: 12%/6%） | 交易过于频繁 | **调整参数：止盈10%，止损5%** |

### 1.3 成功要素（v8继承）

| # | 成功要素 | 说明 |
|---|----------|------|
| **1** | 标准化工具链 | DataLoader + IndicatorCalculator + FactorBacktester |

## 二、v8核心改进方向

### 2.1 核心问题诊断

**v3揭示的根本问题**：策略是"交易驱动"而非"alpha驱动"

```
v3实验数据：
- 单笔平均收益: 0.28% ≈ 随机 (1.07%)
- 高收益来源: 1657次交易 × 0.28% = 466.7%
- 蒙特卡洛: 单笔无显著优势
```

**v8必须改变**：从"高频交易"转向"精选交易+单笔优势"

### 2.2 改进策略

| # | 改进项 | v7做法 | v8做法 | 目标 |
|---|--------|--------|--------|------|
| **1** | 单笔收益目标 | >0.5% | **>1.0%** | 筛选真正有alpha的策略 |
| **2** | 止盈止损 | 6%/4% | **10%/5%** | 减少交易频率，增加单笔收益 |
| **3** | 持仓周期 | 3-20天 | **5-30天** | 更长持仓，趋势跟踪 |
| **4** | 因子组合 | 3因子 | **2-4因子** | 聚焦核心因子，避免过拟合 |
| **5** | 过拟合标准 | 60% | **70%** | 更严格筛选稳定性 |

## 六、评价标准

### 6.1 核心指标（通过门槛）

| # | 指标 | v7阈值 | v8阈值 | 说明 |
|---|------|--------|--------|------|

| **3** | 胜率 | >45% | **>50%** | 概率优势 |
| **4** | 最大回撤 | >-15% | **>-10%** | 风控底线 |

**通过标准**：4项全部达标

### 6.2 过拟合检验（稳定性门槛）

| # | 检验 | v7阈值 | v8阈值 | 方法 |
|---|------|--------|--------|------|
| **1** | 滚动窗口 | ≥60% | **≥70%** | 180天窗口，60天步长 |
| **2** | 蒙特卡洛 | p<0.05 | **p<0.01** | 500次模拟 |
| **3** | 交叉验证 | ≥60% | **≥70%** | 3个训练期 |

**通过标准**：3项全部达标

### 6.3 综合评分

```
最终得分 = 核心分(50%) + 过拟合分(30%) + 稳定性分(20%)

核心分:
  单笔收益: (实际值 - 1.0) / 1.0 × 30分
  夏普比率: (实际值 - 0.5) / 0.5 × 20分

过拟合分:
  滚动窗口通过率 × 30分
  蒙特卡洛显著性 × 40分
  交叉验证通过率 × 30分

稳定性分:
  样本外衰减 × 20分
  最大回撤控制 × 10分
```

## 九、反思机制

### 9.1 每10个模型停下反思

```
累计10个模型
    ↓
记录当前结果（pass/fail分布）
    ↓
检查清单:
  [ ] 通过率是否合理？（>5%说明方向有效）
  [ ] 是否有异常模式？（全pass可能是过拟合）
  [ ] 新发现是什么？
    ↓
决策:
  - 继续：方向有效，继续
  - 优化：参数有问题，调整
  - 放弃：方向无效，换方向
```

### 9.2 阶段结束反思

| 阶段 | 反思项 |
|------|--------|
| 单因子测试 | 哪个因子表现最好？是否与预期一致？ |
| 组合测试 | 最佳组合是什么？是否包含核心因子？ |
| 过拟合检验 | 通过率如何？是否需要调整标准？ |
| 最终报告 | 推荐策略是否可靠？下一步是什么？ |

### 9.3 关键检查点

```
[ ] ETF股票池定义完整（14只+1只参考）
[ ] 时间分割正确（训练期/验证期）
[ ] 因子池定义清晰（趋势/动量/量能/波段）
[ ] 每10个模型停下反思
[ ] IC/IR分析完成
[ ] 过拟合检验完成
[ ] 单笔收益>1.0%门槛达成
[ ] 实验笔记已归档
```
