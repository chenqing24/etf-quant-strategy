## SOP-06 v2.0 开发复盘

### 问题1：首次实现未按SOP

**现象**：直接改代码（跨4个文件），没有先输出设计。

**正确做法**：Phase 3 必须输出设计文档，等确认后再实现。

### 问题2：未参考业界最佳实践

**现象**：第一次设计没有调研，直接拍脑袋。

**正确做法**：
1. 先搜索 GitHub 交易日志项目
2. 参考 NormalizedTrade schema、session_analyzer.py
3. 补充情绪追踪字段
4. 自评分后输出设计

### 问题3：方案评分后才落地

**改进后做法**：
```
发现问题 → 调研 → 评分 → 确认 → 实现
```

### 问题4：Git Rebase 冲突

**根因**：回滚后 push，远程已有新 commit。

**正确做法**：个人分支用 merge 或 force push。

### 问题5：dataclass 顺序错误

**根因**：`@dataclass` 装饰器位置不对。

**正确做法**：常量放类外部，装饰器紧贴类定义。
