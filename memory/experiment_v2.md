# ETF多因子挖掘实验记录

## 实验教训（2026-05-31）

### 教训1：发现重大问题立即修复
- v3.0发现IR=IC错误，但没有修复
- 继续跑完182个模型，结论不可用

### 教训2：反思要深入，不只是记录
- 反思点只记录数字，没问"为什么"
- 异常现象（衰减为负）没有追问原因

### 教训3：先检查数据前提
- 部分ETF训练期数据不足100天
- 应在开始前验证数据量是否足够

### 教训4：过拟合检验要深入分析
- 不仅看通过/失败，要分析收益来源
- "交易驱动" vs "alpha驱动"

### 教训5：使用现有工具，禁止重复造轮子 ⚠️
- v1.0~v5.0 每次重写脚本（80%代码重复）
- 现有 `src/backtest/engine.py` 完全被忽略
- **正确做法**：动手前必须搜索现有代码库

### 教训6：工具使用标准化
- 数据加载 → DataLoader
- 指标计算 → IndicatorCalculator  
- 回测 → FactorBacktester
- 评价 → BacktestResult 统一格式

## 项目前提条件

1. **量化类型**：个人量化，中低频
2. **持仓周期**：≥3天，≤20天（强制调仓）
3. **交易频率**：低频（精选交易）
4. **单笔目标**：>0.5%（ETF合理预期）
5. **工具标准化**：必须使用现有工具
